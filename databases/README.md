# Data files (not included)

The two official files used by `script/dropout_analysis.R` are public datasets from the Chilean Ministry of Education but are too large to store in this repository.

| File | Content |
|---|---|
| `rendimiento_2023.csv` | Academic performance 2023, one row per student |
| `20240913_Matrícula_unica_2024_20240430_WEB.CSV` | Official enrolment 2024, one row per student |

They were provided with the technical assessment ([Google Drive folder](https://drive.google.com/drive/folders/1DT-R1INN3gBh_n6K-IE5SXYyp9DMSnBl?usp=drive_link)) and are also published on the Ministry's open data portal (datosabiertos.mineduc.cl). Place them in this `databases/` folder before running the script.
